### Executable change

- Improved `scripts/ask_offline.py` interactive GGUF chat. Previously `--max-history-turns` capped only the number of turns; eight very long turns could still exceed the configured context. The chat now uses the loaded runtime tokenizer to estimate each message's token count, adds a small per-message overhead and reserves 64–256 context tokens for chat-template/control overhead.
- Added `--max-history-tokens` (default 1024) to cap prior turns separately from the current prompt. It retains the newest contiguous complete user/assistant pairs first. If the current prompt exceeds the remaining safe input budget, it is refused before `create_chat_completion` is called; it is not silently truncated. The result reports the last input-token estimate and the selected history limits.
- This estimate is not an exact rendered chat-template count. The backend remains authoritative and may still report a context error for unusual templates. History remains in RAM only; no API, persistence or model claim was added.
