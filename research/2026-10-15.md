### Implemented and collected

Expanded `collect_wikipedia.py` from a fixed one-off pilot into a bounded batch
collector. It accepts a versioned title list, repeated existing-corpus inputs and a
1–20 batch limit. It rejects duplicate requested titles before network access, then
checks canonical source URL, Wikipedia page ID and NFC/whitespace-normalized exact
text against all supplied earlier rows and the current batch. It records missing,
short, incomplete, duplicate and over-limit candidates. An incomplete requested
batch writes no output. Each accepted row retains revision ID/URL, history URL,
attribution, CC BY-SA 4.0 license/URL, extraction note and exact text SHA-256.

### Limits and next action

Wikipedia text may be present in base-model pretraining and is not a clean held-out
benchmark. Public encyclopedia text can still contain personal facts, inaccuracies,
template artifacts and uneven Mongolian. The batch count is collection throughput,
not human approval or quality improvement. Next runs should pass the pilot and every
earlier daily batch through `--existing`, add four further 20-document manifests,
then perform human/privacy/quality/rights and semantic-overlap review before any
instruction conversion or training.
