### Executable change

Added scripts/export_offline_bundle.py and tests/test_offline_bundle.py.

The packaging command copies an existing local full/merged safetensors model or base-plus-adapter directory to a new destination outside Git. It requires an exact 40-character upstream revision, separate weights/code license labels, explicit model-card/license URLs, exact runtime pins, a tokenizer vocabulary and explicit chat template. It refuses symlinks, pickle-style model weights, mutable revisions, unpinned runtime ranges, pre-existing destinations and bundles above the default 16 GiB source cap. A manifest stores per-file SHA-256 and size, tokenizer-template identity, upstream attribution, runtime pins and a bundle identity hash. Verification rehashes the complete inventory without loading tensors or accessing the network. Failed staging/publication is marked incomplete rather than silently treated as valid.

The manifest deliberately states that license metadata is operator-supplied and not independently legally verified. File-hash verification does not prove tensor compatibility, successful inference, answer quality or OS-level network isolation. The test fixture uses tiny placeholder bytes named as safetensors files; it exercises packaging integrity, not a real model runtime.
