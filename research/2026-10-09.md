## Нэг хэрэгжүүлсэн ажил: experiment artifact integrity verifier

Өмнөх comparison gate нь хадгалсан `scores.json` болон metadata-г уншдаг боловч raw prediction-оос оноо, хугацаа, token aggregate-ийг бие даан дахин тооцож баталгаажуулдаггүй байв. `scripts/verify_experiment.py` нэмээд:

- evaluation файлын SHA-256 metadata-тай таарч байгаа эсэх, status=`completed` эсэхийг шалгана;
- prediction ID/хариултыг evaluation case-тай тулгаж exact-match score-ийг дахин тооцно;
- секунд finite/non-negative, token count non-negative integer, token-limit flag boolean эсэхийг шалгана;
- нийт хугацаа, generated tokens, token-limit hits metadata-тай таарч байгаа эсэхийг батална;
- input metadata, predictions, scores болон cases-ийн SHA-256-ийг шинэ `integrity.json` тайланд хадгална;
- зөрүүтэй үед exit 1 буцааж, өмнөх integrity report-ийг дарж бичихгүй.
