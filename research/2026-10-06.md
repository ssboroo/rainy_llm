## Нэг хэрэгжүүлсэн ажил: буруу хэмжилтийг харьцуулалтаас хасах

`compare_benchmarks.py` өмнө нь NaN/Infinity хугацаа, VRAM, cost-ийг тоон төрөл гэж хүлээж авах боломжтой, буруу төрлийн хугацаа/нийт тоон дээр validation хийсний дараа ч division алдаагаар унаж байв. Baseline-ийн missing утга promotion-д шалгагдахгүй байсан.

- Тоон хэмжилтүүд finite байх ёстой; bool нь хэмжилт биш.
- Total/correct/missing нь зөв бүхэл тоо, хоорондоо нийцсэн байх ёстой; correct + missing нь total-оос их байж болохгүй.
- JSON object биш input болон буруу төрөлтэй хэмжилтэд validation report гаргана.
- Baseline эсвэл candidate хариу дутуу бол technical promotion eligibility=false.
- CLI буруу numeric input-д traceback бус strict JSON report, exit 1 гаргана.
- Eligibility нь release approval биш, хүний review/held-out validation-ийг орлохгүй гэдгийг report-д тодруулав. Prediction файл дахин оноолох, provenance бүрэн баталгаажуулах ажил энэ өөрчлөлтийн хүрээнд хийгдээгүй.
