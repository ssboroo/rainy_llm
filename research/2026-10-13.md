## Product implementation follow-up — 17:26 onward

Implemented `scripts/search_documents.py`: local UTF-8 TXT/Markdown search with SQLite FTS5 Unicode tokenization and BM25. Official reference checked: https://www.sqlite.org/fts5.html. This is a lexical baseline, not a claim of best Mongolian retrieval or semantic understanding. Each hit contains an original excerpt, file-relative path, line range and source SHA-256. A bounded in-memory index is rebuilt per call, reflecting changes/deletions on the next call without retaining a database. Hidden paths and symlinks are skipped; input size limits and invalid UTF-8 fail closed.

## Кодын өөрчлөлт

`scripts/review_evaluation.py summary` subcommand нэмэв. Энэ нь case fingerprint болон review ID-г шалгаад `pending`, `ready-accept`, `incomplete`, `rejected`, `missing`, `stale`, `invalid` төлвийг нийт болон category бүрээр тоолно; unknown review ID-г тусад нь гаргана.
