# CPU pipeline implementation

Implemented normalization, exact deduplication, connected source/prompt grouping, seeded split export and an input-hash manifest. Added 24 AI-authored draft Mongolian evaluation cases and offline scoring with missing answers included in the denominator.

Validation: 16 unittest tests passed on Python 3.12. CLI preparation succeeded on the single format example, with expected empty validation/test warnings. All 24 cases passed schema/scorer self-check. A fixture containing reference answers scored 1.0; this checks software only and is NOT an LLM benchmark result.

Known limits: whole-file memory use; first duplicate provenance retained; no semantic deduplication or PII/license verification; draft evaluation awaits human review; exact-match scoring is format-sensitive. Training and inference are not implemented.
