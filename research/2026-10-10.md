## Нэг хэрэгжүүлсэн ажил: fuzzy evaluation leakage audit

Exact normalized overlap gate нь үг нэмсэн, бага зэрэг өөрчилсөн prompt-ийг алдаж болох тул `scripts/audit_evaluation_overlap.py` нэмэв:

- evaluation prompt болон training instruction/input-ийг Unicode-normalized character n-gram set болгон Jaccard similarity тооцно;
- report-д training prompt/output текст огт хуулалгүй case ID, training file index, row number, score л хадгална;
- threshold, n-gram size, хамгийн их pair count-ийг validate хийж, NaN/буруу төрөл болон хэт том pairwise run-ийг блоклоно;
- input case болон training файлуудын SHA-256-ийг reproducibility-д хадгална;
- `--fail-on-match` сонголтоор CI/release gate болгон ашиглаж болох ба output файлыг дарж бичихгүй.

Энэ нь lexical candidate finder; semantic paraphrase, translation эсвэл pretrained base model contamination-ийг бүрэн илрүүлэхгүй. Candidate бүрийг хүн шалгана.
