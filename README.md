# RAINY LLM

Монгол хэлний нээлттэй LLM хөгжүүлэх судалгаа, өгөгдөл, сургалт, үнэлгээний төсөл.

## Одоогийн төлөв

Эхний суурь хувилбар. Загвар хараахан сургаагүй, GPU туршилт болон чанарын benchmark хийгдээгүй.

## Чиглэл

1. Нээлттэй жинтэй суурь загваруудыг Монгол тестээр харьцуулах.
2. Лиценз, эх сурвалж нь тодорхой Монгол өгөгдөл бэлтгэх.
3. LoRA/QLoRA сургалтын pipeline хэрэгжүүлэх.
4. Сургалтаас тусгаарласан тестээр чанар хэмжих.
5. Үнэлгээний дараа inference API, Docker хувилбар гаргах.

Qwen3-4B ба Gemma 3-4B нь эхний харьцуулах нэр дэвшигчид; сонголт эцэслээгүй.

## Өгөгдлийн шалгалт

Python 3.10+; нэмэлт dependency шаардлагагүй.

```bash
python scripts/validate_data.py data/examples.jsonl
python -m unittest discover -s tests -v
```

Жишээ өгөгдөл нь зөвхөн форматын smoke test бөгөөд сургалтын корпус биш.
Дэлгэрэнгүй: `docs/ROADMAP.md`, `docs/DATA.md`, `research/2026-09-29.md`.

## Өдөр тутмын ажил

ChatGPT-ийн scheduled task-аар судалгаа болон хязгаарлагдмал өөрчлөлт хийнэ. Энэ нь GitHub Actions дээр ажилладаг GPU сургалтын cron биш. Шинэ кодыг хөгжүүлэлтийн branch-д push хийж, тест ба commit холбоосыг тайлагнана. GPU, төсөв тохиртол төлбөртэй сургалт эхлүүлэхгүй.
